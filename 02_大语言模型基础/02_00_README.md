# 02 大语言模型基础

## 本章目的

本章面向 AI 产品经理入门，目标不是理解数学推导或自行训练模型，而是能够：

- 解释 LLM 如何从输入生成回答；
- 理解模型的能力边界与风险；
- 在质量、成本、速度、安全之间做初步选型；
- 判断何时使用 Prompt、RAG、工具调用或微调；
- 设计基础的模型评测与上线检查。
