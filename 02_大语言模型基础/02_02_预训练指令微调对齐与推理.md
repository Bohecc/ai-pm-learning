# 02 02 预训练 指令微调 对齐与推理

## 1. 为什么同一模型家族会有不同版本

同一模型家族可能有基础模型、聊天模型、推理模型等不同版本。它们的行为差异不仅来自参数规模，也来自训练目标和后训练方式。

## 2. 预训练

预训练使用大量文本、代码等数据，让模型学习语言模式和预测下一个 Token。

可以把它理解为“广泛阅读并学习语言规律”。但预训练不代表模型拥有实时、完整或绝对正确的事实知识。

## 3. 后训练

后训练（Post-training）是预训练完成后，为让模型更适合实际任务而进行的一系列训练和优化。

### 指令微调

指令微调常称 SFT（Supervised Fine-Tuning）。它使用“指令 → 理想回答”形式的样本，帮助模型更好地：

- 理解用户任务；
- 遵循指定格式；
- 完成总结、提取、问答等任务；
- 以更符合预期的方式对话。

### 偏好对齐

偏好对齐让模型学习更有帮助、更安全、更符合指令和更可靠的回答倾向。

RLHF（基于人类反馈的强化学习）是偏好对齐的一类重要方法，但不是唯一方法。后训练还可能使用其他偏好优化、安全训练和评测驱动的方法。

## 4. 基础模型 聊天模型与推理模型

| 类型 | 常见定位 | 产品提醒 |
|---|---|---|
| 基础模型 | 接近预训练底座，适合继续训练或研究 | 不是“简单版聊天模型”，通常不直接面向普通用户 |
| 聊天/指令模型 | 更适合问答、总结、提取和多轮对话 | 多数产品第一版的常见起点 |
| 推理模型 | 更适合复杂、多步骤的分析和规划任务 | 不代表永远正确；可能更慢、更贵 |

## 5. 推理 Inference

在本章语境中，推理指模型接收输入后，利用已经训练好的参数进行计算并生成输出的过程。它不是“像人一样思考”的证明。

## 产品意义

经过指令微调和对齐的模型仍然可能：

- 产生幻觉；
- 误解复杂或冲突指令；
- 遗漏资料中的条件；
- 在高风险任务中给出不合适的确定性建议。

因此，产品仍需 Prompt、检索、工具、评测和人工介入等系统机制。

## 参考答案

1. 预训练学习语言模式和下一个 Token 预测；指令微调学习理解任务、遵循格式和给出理想回答。
2. 因为模型仍可能幻觉、误解指令或遗漏条件，且不天然拥有实时事实与外部权限。
