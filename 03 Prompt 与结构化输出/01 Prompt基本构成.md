# 01 Prompt 基本构成

## 通俗定义

一个 Prompt 是给模型的任务说明，通常包括目标、上下文、约束和输出格式。

- 目标：希望模型完成什么。
- 上下文：模型需要知道的背景和材料。
- 约束：能做什么、不能做什么、缺失信息如何处理。
- 输出格式：结果应如何组织。

## 为什么重要

结构不清会导致结果方向错误、质量不稳定、无法验收，也难以接入产品系统。

## 产品案例

```text
目标：提取城市更新访谈中的需求、痛点和关注重点。
上下文：结果供产品团队进行需求分析。
约束：只依据访谈内容；区分事实、推断和待确认问题；没有依据时写 null。
输出格式：核心需求、主要痛点、关注重点、证据、待确认问题；500 字以内。
```

## 常见误区

- 角色设定不等于任务目标。
- “帮我分析”“不要过度解读”不够可测试。
- 字数限制不等于完整输出格式。
- Prompt 不能替代权限和安全机制。

## 小测试

把“帮我分析一份城市更新访谈”补充为目标、上下文、约束和输出格式。

## 参考答案

目标是提取需求、痛点和关注重点；上下文是城市更新访谈及其使用场景；约束是只依据材料、区分事实和推断、无依据时不猜；输出格式是固定栏目并限制长度。
