# 03 Few-shot 与反例

## 通俗定义

Few-shot 是在 Prompt 中提供少量输入—输出示例，让模型学习任务标准。反例用于说明相似输入不应被错误归类，边界案例用于测试模糊或临界情况。

## 为什么重要

示例能把抽象规则变成可观察标准，帮助统一分类、风格和验收边界。

## 产品案例

```text
输入：上传 PDF 后页面一直无反应。
输出：功能问题

输入：报告漏掉容积率限制。
输出：内容问题

输入：信息正确但标题层级混乱。
输出：表达问题，不应归入内容问题。
```

## 常见误区

- 示例不是越多越好。
- 规则与示例不能冲突。
- 只给典型正例，模型可能无法处理边界情况。

## 小测试

为“判断反馈属于功能问题还是内容问题”设计两个正例和一个边界或反例。

## 参考答案

正常运行但信息错误属于内容问题；系统无法完成操作属于功能问题；信息正确但展示困难属于表达或其他问题，不应强行归入内容问题。
