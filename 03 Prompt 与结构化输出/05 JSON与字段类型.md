# 05 JSON、字段类型与结构化输出

## 通俗定义

结构化输出要求模型按照固定字段返回结果。JSON 是常见的数据表达格式。

```json
{
  "需求": "导出 Excel",
  "优先级": 4,
  "是否需要人工复核": true,
  "相关人员": ["甲方", "设计团队"],
  "负责人": null
}
```

## 为什么重要

固定字段便于前端展示、数据入库、排序统计、自动校验和错误处理。

## 字段与类型

- 字段：信息名称，例如“优先级”。
- 字段值：具体内容，例如 `4`。
- 文字：字符串。
- 数字：整数或小数。
- 布尔值：`true` 或 `false`。
- 列表：多个值组成的数组。
- `null`：字段存在但暂时没有值。

## 常见误区

同一字段不能一会儿使用数字、一会儿使用文字；字段名也应统一。

## 小测试

为会议纪要提取器设计五个字段，并写出至少一个字段的类型。

## 参考答案

需求、痛点、证据、负责人、待确认问题；其中需求是文字，证据和待确认问题可以是文字列表，负责人可以是文字或 `null`。
