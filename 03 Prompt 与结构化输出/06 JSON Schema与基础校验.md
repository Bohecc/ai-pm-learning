# 06 JSON Schema、枚举与基础校验

## 通俗定义

JSON Schema 是输出检查表，用于规定字段、类型、必填项和允许值。

## 产品案例

```text
需求：必须是文字。
优先级：必须是数字，只能是 1、2、3、4、5。
是否需要人工复核：必须是 true 或 false。
负责人：字段必须存在，可以是文字或 null。
```

## 为什么重要

Schema 能自动发现漏字段、类型错误和非法值，避免错误结果直接进入系统。

## 常见误区

Schema 能检查格式和类型，但不能保证事实真实，也不能替代权限控制。

## 小测试

判断以下结果：

```json
{
  "优先级": "高",
  "是否需要人工复核": "否"
}
```

## 参考答案

不合格。“高”是文字而不是 1–5 的数字；“否”是文字而不是布尔值；如果负责人是必填字段，它也缺失。合格写法示例：

```json
{
  "优先级": 5,
  "是否需要人工复核": false,
  "负责人": null
}
```
