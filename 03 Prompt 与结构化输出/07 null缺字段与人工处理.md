# 07 null、缺字段与人工处理

## 通俗定义

- 有信息：填写实际值。
- 字段存在但没有信息：填写 `null`。
- 字段缺失：输出结构不完整，可能是模型漏填。

## 为什么重要

系统必须区分“材料没有提供”和“模型忘记输出”，并据此决定继续处理、提示用户还是转人工。

## 产品案例

```json
{
  "task": "确认施工图纸",
  "owner": null,
  "deadline": null,
  "requires_review": true
}
```

## 常见误区

- 把缺字段和 `null` 混为一谈。
- 用“未知”“没有”“待定”随意替代约定的 `null`。
- 没有证据时让模型猜测。

## 小测试

规则要求负责人字段必须存在，可以是文字或 `null`。判断：`负责人: null` 合格；没有负责人字段不合格。

## 参考答案

正确。`null` 表示字段存在但暂时没有值；缺字段表示输出结构不完整。
