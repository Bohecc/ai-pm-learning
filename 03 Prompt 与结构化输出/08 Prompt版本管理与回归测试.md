# 08 Prompt 版本管理与回归测试

## 通俗定义

版本管理是保存 Prompt 的不同版本；回归测试是用固定测试集比较修改前后的结果，确认新修改没有破坏旧能力。

## 产品案例

- v1：提取需求和痛点。
- v2：增加证据字段。
- v3：没有证据时输出 `null`。

测试集应同时包含正常、边界、空输入和高风险案例。

## 常见误区

- 只保存最终版本。
- 只测试正常案例。
- 只看答案是否“像对的”，不检查格式、成本、延迟和安全。

## 小测试

新增规则“没有证据时输出 null”后，写一个正常案例和一个缺失信息案例。

## 参考答案

正常案例：有明确需求和原文证据，预期提取需求并保留证据。缺失案例：没有负责人信息，预期负责人为 `null`，不得猜测。
