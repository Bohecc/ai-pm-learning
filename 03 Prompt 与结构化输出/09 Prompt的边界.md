# 09 Prompt 的边界

## 通俗定义

Prompt 负责指导模型行为，但不能替代事实检索、权限控制、工具验证、安全检查和人工审批。

## 对应关系

- 最新事实：检索可靠来源。
- 用户能查看什么：权限控制。
- 工具能否执行高风险操作：工具参数校验、白名单和人工审批。
- 没有证据时不猜：Prompt 可作行为约束。

## 产品案例

退款助手可以由 Prompt 要求模型判断退款条件，但金额上限、身份验证和实际退款权限必须由后端和工具系统控制。

## 常见误区

“不要越权”不能替代权限系统；模型回答自信不代表事实可靠；工具返回结果也需要验证。

## 小测试

判断四类问题的主要机制：只能查看自己的订单、回答最新政策、防止高金额退款、没有负责人时输出 `null`。
