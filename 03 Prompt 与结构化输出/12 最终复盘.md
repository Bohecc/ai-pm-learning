# 第三章最终复盘

## 一句话总结

Prompt 负责把任务说清楚，结构化输出负责让结果稳定，Schema 负责检查格式，检索负责提供事实，权限和工具系统负责控制风险。

## 已掌握内容

- Prompt 的目标、上下文、约束、示例和输出格式。
- System、Developer、User 和 Context 的分工。
- Few-shot、反例、边界案例和任务拆解。
- JSON 字段、字段值、文字、数字、布尔值、列表和 `null`。
- JSON Schema、必填字段、枚举和基础校验。
- 缺字段与 `null` 的区别。
- Prompt 版本管理和回归测试。
- Prompt 与检索、权限、工具验证、安全机制的边界。
- CoT 的边界和简洁、可验证的说明输出。

## 仍需持续练习

- 设计更完整的 JSON Schema。
- 将业务规则转成可执行验收条件。
- 设计正常、边界、异常和高风险测试案例。
- 在真实项目中比较 Prompt 版本、格式错误、成本和延迟。
- 明确何时转人工，而不是只要求模型自行判断。

## 岗位层面的完成标准

达到初级 AI 产品岗位可用程度，不要求成为工程师，但应能：

- 看懂基本 JSON 和 API 输出；
- 与工程师讨论字段、类型、校验和错误处理；
- 写出可测试的 Prompt；
- 设计验收案例和失败分支；
- 识别事实、权限、安全和人工介入边界。
