# 01 传统 AI 与机器学习基础

## 本章定位

本章面向 AI 产品经理入门，不要求推导算法公式或手写模型。学习目标是能识别问题类型、理解数据和评估指标，并在产品讨论中判断应该使用规则、传统机器学习还是大模型。

## 学习深度

| 内容 | 建议深度 | 完成标准 |
|---|---:|---|
| 监督学习、无监督学习、半监督学习 | ★★☆☆☆ | 能用自己的话解释差异并判断案例 |
| 分类、回归、聚类 | ★★☆☆☆ | 能根据输出和标签情况判断任务类型 |
| 训练集、验证集、测试集与数据泄露 | ★★★☆☆ | 能解释数据划分并识别常见泄露 |
| 准确率、精确率、召回率、F1、AUC | ★★★☆☆ | 能根据误报和漏报代价选择指标 |
| 线性回归、逻辑回归、决策树、随机森林、K-means | ★★☆☆☆ | 知道用途、优缺点和典型场景 |
| KNN、朴素贝叶斯、SVM、CNN、RNN、LSTM、GAN | ★☆☆☆☆ | 能辨认名称和大致用途 |
| 数据清洗、特征工程、标注质量与偏差 | ★★★☆☆ | 能发现常见数据问题及其产品影响 |

# 02 大语言模型基础

## 本章目的

本章面向 AI 产品经理入门，目标不是理解数学推导或自行训练模型，而是能够：

- 解释 LLM 如何从输入生成回答；
- 理解模型的能力边界与风险；
- 在质量、成本、速度、安全之间做初步选型；
- 判断何时使用 Prompt、RAG、工具调用或微调；
- 设计基础的模型评测与上线检查。
